Keyboard guide — Windows & MacBook

Windows Alt = MacBook Option (⌥). Enter is usually labelled Return (↵) on MacBook. Tab (⇥), Shift (⇧), Space and arrow keys work on both systems.

Whole page: Tab / Shift+Tab move between controls. Alt + arrow keys (Mac: Option + arrow keys) move between visible controls without changing text editing. Alt+1: Session; Alt+2: Codebook; Alt+3: Coding; Alt+4: Summary; Alt+5: Save/export. Enter / Space activates buttons and opens expandable sections.

Session information: Enter / Shift+Enter move to the next / previous field. Dropdowns retain their native arrow-key controls. After each selection, focus moves automatically to the next category: Teacher → Position → On task → Appropriate screens, then the next interval. Coding: Left / Right move through options and Skip/Resume; Up / Down move between intervals, including across pages. Enter / Space selects an option. Keys 1–9 choose an option in the focused category; 0 chooses the tenth Position option (Other). Delete / Backspace clears the focused category; on Mac use Delete (⌫). New coding pages focus the first Teacher option automatically.

Classroom layout: Tab enters the grid once. Arrow keys move between cells; Enter / Space applies the selected mark. Shift + arrow keys select a rectangular area; Enter / Space applies the mark to the selection. Escape cancels the selection. Tab leaves the grid. Select a mark or Undo with Enter / Space.

Choose one code in each of the four groups per row. Entries save automatically, including unfinished rows. The page advances automatically when all five intervals are complete or skipped. Previous page and Next page are available at any time. Click Resume or select a code to return to a skipped interval.

Counts and percentages

n = completed coded intervals. Percentages = category count ÷ n × 100. Each of the four groups totals n (100% when n > 0). Sheet 1: intervals 1–5; sheet 2: 6–10; sheet 3: 11–15, and so on. Only complete intervals contribute to counts and percentages. Skipped and incomplete intervals are excluded from n.
